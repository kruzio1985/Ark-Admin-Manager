Zapora (Firewall)

Aby dostęp zdalny działał, porty muszą być otwarte w Windows Defender Firewall. Kliknij poniżej, aby dodać reguły automatycznie.

Jak to działa
  1. Włącz dostęp zdalny — aplikacja serwuje panel pod adresem http://IP-serwera:8090
  2. Otwórz ten adres w przeglądarce na innym komputerze w sieci LAN
  3. Włącz auto-start, aby po restarcie serwera aplikacja sama się uruchomiła
  4. Dodaj reguły zapory, aby port 8090 był dostępny z innych komputerów

❓ Help / Pomoc

🚀 Pierwsze kroki

1. Przejdź do Settings → First-Install i kliknij ⬇ Zainstaluj brakujące (SteamCMD + VC++ + DirectX).

2. W Servers kliknij + New Server (albo Auto-detect, jeśli serwery już istnieją na dysku).

3. Ustaw porty (unikalne!), hasło admina (RCON) i kliknij 📥 Create & Install.

4. Włącz 🛡 Auto-Restart on Crash i Auto-Start (Guardian pilnuje, żeby serwer nie padł).

5. Uruchom serwer przyciskiem ▶. Stop zawsze robi bezpieczny zapis świata (SaveWorld→DoExit).

⚙ Config Editor — czyta USTAWIENIA LIVE z plików serwera

Edytor czyta realne wartości z Game.ini i GameUserSettings.ini na serwerze — pokazuje to, co faktycznie jest ustawione, i nie nadpisuje niczego, czego nie zmienisz. Przy zapisie ustawienia są scalane z istniejącym plikiem (nie kasowane).

Przyciski: 📄 Generate INI (podgląd plików), 📸 Snapshot (zapisz stan), ↩ Przywróć (rollback), 📤 Export / 📥 Import.

🎁 Give Item i Paczki

Player Manager → 🎁 Give — daj dowolny przedmiot graczowi (katalog 1432 itemów z wyszukiwarką).

🎁 Paczki / Prezenty — twórz paczki welcome (auto dla nowych graczy, z opóźnieniem w minutach) i gift (wysyłka do wybranego lub wszystkich online).

🔗 Cluster

Twórz klaster, dodawaj serwery. ASE wymaga pełnej ścieżki folderu (np. D:\cluster_bio). Przyciski: ▶ Start all / ⏹ Stop all / 🔍 Diagnose / 📸 Baselines (rollback configu klastra).

💬 Discord Bot — komendy

ark!status — status serwerów · ark!list — lista serwerów

ark!players [nazwa] — gracze · ark!start/stop/restart <nazwa>

ark!update <nazwa> · ark!backup [nazwa] · ark!broadcast <msg>

Cross-chat: włącz w Discord Bot → wiadomości z gry trafiają na kanał, a wiadomości z kanału do gry.

💾 Backupy

+ Create Backup — pełny backup (Saved + config). 🔄 Restore — przywróć (robi kopię bezpieczeństwa przed nadpisaniem). 🧹 Rotacja — usuwa stare (wg dni w config). ☁ — wysyłka na FTP.

🛡 Guardian (self-healing)

Włącza się w ✏ Edytuj serwer: Auto-Restart on Crash (restart po padnięciu) i Auto-Start (start przy uruchomieniu aplikacji). Guard co 60s sprawdza procesy.

🌐 Dostęp zdalny (web)

Otwórz w przeglądarce: http://IP_SERWERA:8090 — pełny interfejs działa z każdego urządzenia w sieci. Port zmienisz w Settings → Remote Access.
